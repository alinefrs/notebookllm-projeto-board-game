# Projeto NotebookLM | Aprenda sobre o universo de Board Games.
Projeto de NotebookLLM que fornece uma visão detalhada do universo dos jogos de tabuleiro modernos, o conteúdo do notebook é baseado em fontes teóricas selecionadas. O link abaixo dá acesso ao notebookLM desenvolvido neste projeto:

https://notebooklm.google.com/notebook/27456a0d-e066-4656-8275-8906c94cec2a


## Objetivo do Projeto
Criar um sistema de IA que funcione como um guia sobre o universo de jogos de tabuleiro, capaz de:

- explicar o que são jogos de tabuleiro e apresentar seus principais conceitos;
- organizar informações sobre categorias, mecânicas, estilos e níveis de complexidade dos jogos;
- recomendar jogos com base no perfil, gosto e experiência do usuário;
- tirar dúvidas sobre regras, dinâmica e funcionamento dos jogos;
- sugerir opções de jogos para diferentes contextos, como família, casal, amigos, festas ou grupos competitivos;
- servir como fonte de consulta rápida e educativa sobre o universo board gamer.

## Tecnologias Utilizadas:
- NotebookLM;
- Inteligência Artificial Generativa.

## Exemplos de uso do NotebookLM:
- Interações individuais: exemplos de prompts voltados para dúvidas específicas.
- Resumo textual: explicações organizadas em texto, reunindo os principais pontos de forma clara e objetiva.
- Resumo em áudio: apresentação dinâmica do conteúdo, facilitando a compreensão e o consumo rápido das informações.
- Vídeo: demonstrações visuais que sintetizam os temas trabalhados de forma mais interativa e didática.
